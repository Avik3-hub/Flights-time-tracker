# Счётчик налёта 2.0.1

Исправление оформления поверх 2.0. `versionName = "2.0.1"`, `versionCode = 26`.

- Компоновка обзора переработана по трём исходным эскизам: общий приборный
  блок в «Классике», светло-синий фон и синий блок налёта в «Синей», чёрный
  фон и отдельные приглушённые карточки в AMOLED.
- Новый подробный растровый Ми-171 с прозрачным фоном вместо упрощённого
  вектора. Иллюстрация создана по согласованному эскизу; используется также
  на заставке Android 12+.
- Крупные цифры с автоматическим подбором размера, кириллический шрифт
  Russo One, компактные последние три полёта и кнопка добавления под ними
  (в AMOLED — в заголовке списка).
- Из «Ещё» убраны только дублирующие переходы «Дежурства» и «Отчёты и Excel».
  Сам ввод дежурств, отчёты, импорт и экспорт остались на прежних экранах.
- Выбор оформления доступен только через «Ещё»; верхняя кнопка удалена.
- Данные, расчёты, applicationId и настройки подписи не менялись.

## Визуальная проверка

`design/previews/{classic,blue,amoled}.png` — рендеры рабочего Compose-кода
через Paparazzi 1.3.4, конфигурация Pixel 5, условные записи за апрель 2026.
В приложении эти демонстрационные записи не создаются. Дополнительно проверены
пустой список и системный масштаб шрифта 1.4. При большом шрифте карточки
метрик переходят в вертикальное расположение; экран прокручивается.
Проверочное подключение Paparazzi не включено в зависимости приложения.
Рендеры не заменяют проверку на физическом телефоне.

Для проверки на телефоне: переключить все три темы через «Ещё», проверить
обзор с пустым и заполненным месяцем, увеличить системный размер шрифта,
открыть полёт из последних записей, добавить полёт и проверить импорт/экспорт
из журнала. Перед установкой рекомендуется сохранить резервную копию данных.
