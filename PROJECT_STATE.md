# Состояние проекта — Flights-time-tracker

Обновлено: 2026-10-18. Основная ветка: `main`.

## Назначение
Android-приложение «Счётчик налёта» для учёта полётов, дежурств, налёта и связанных расчётов.

## Что есть в репозитории
- Интерфейс Jetpack Compose: обзор, журнал, ввод/редактирование полётов, настройки и темы оформления.
- Локальная база Room, расчёты, импорт и экспорт Excel, виджет; в репозитории есть тесты миграции и данных.
- Заметка `RELEASE-2.1.md` описывает тип полёта, миграцию Room 5 → 6 и проверки оформления. Текущий `app/build.gradle.kts` указывает версию 2.0.2 (code 33), поэтому номер последнего фактического выпуска нужно сверить по APK и истории сборок.

## Открытые вопросы
- В заметке 2.1 прямо указана необходимость проверки холодного запуска, импорта старого Excel, тем и системной заставки на физическом телефоне. Результат такой проверки в изученной документации не зафиксирован.
- Корневой README пока содержит только название проекта.
